# RANGO! - Sistema Integrado de  Gestão de Entregas Gastronômicas (SIGEG)
O "RANGO!" é uma plataforma completa de delivery que integra toda a jornada de pedidos gastronômicos entre clientes, restaurantes e entregadores. O aplicativo facilita a vida do usuário com pagamentos flexíveis, recomendações de pratos e rastreamento de entregas em tempo real, ao mesmo tempo em que oferece aos restaurantes um painel de gestão e faturamento, e aos entregadores, um sistema inteligente de roteirização. É a solução ideal para garantir que o pedido chegue rápido e o restaurante gerencie tudo de forma simples e segura.
